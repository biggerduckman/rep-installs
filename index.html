Location is off

This app needs permission to use your location, only on this phone, to center the map and sort jobs by distance. It isn't saved or sent anywhere.

  1. Open Settings → Privacy & Security → Location Services and make sure it's On.
  2. In the same list, tap Safari Websites and choose While Using the App.
  3. In Safari, tap aA → Website Settings → Location → Allow.
  4. If you opened this from the Home Screen icon and denied location earlier, delete the icon, add it again from Safari, then tap Use my location and Allow.
